# Touchline final logo

The mark is a goal seen side-on: a solid right-angled shape whose diagonal ends in a sharp point, with an empty triangular cut-out. Below it sits a separate touchline bar. On a 100-unit grid every stroke is 12 units, the gap is 6 units, and the bar spans exactly the shape's left and right edges (x 12 to 90).

- On dark: the shape is white #FFFFFF, the bar is lime #C9F24A and the background is #0E1217.
- One colour: everything is black #000000.
- Wordmark: TOUCHLINE in Barlow Condensed ExtraBold, cap height equal to the shape's height (excluding the bar), baseline on the shape's base. League names such as EJA are set in Barlow Condensed Medium, separated by a vertical rule half a stroke wide (6 units).
- All text in the SVGs is converted to outlines, so no fonts are needed.
